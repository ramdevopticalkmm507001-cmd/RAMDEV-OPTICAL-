# Ramdev Opticals V5.2 — Payment Ready

Added:
- Payment fields in the orders database
- Provider-neutral payment order endpoint
- Payment verification endpoint contract
- Razorpay integration adapter instructions
- Backward-compatible SQLite schema upgrade

## Important
This version is **payment-ready, not live-payment-enabled**. A real Razorpay integration requires the merchant's Razorpay account and API credentials. Those credentials must stay on the server.

## Intended live flow
Customer checkout
→ create database order
→ backend creates Razorpay order
→ Razorpay checkout
→ backend verifies signature
→ order becomes `paid`
→ WhatsApp confirmation can use 8008564974

Do not publish the demo payment endpoints as a live payment system until server-side Razorpay verification is implemented.
