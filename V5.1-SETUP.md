# Ramdev Opticals V5.1

V5.1 adds:
- Authenticated admin API using an environment token
- Admin login page
- Protected order and product management
- Checkout API contract for saving orders to SQLite
- Existing WhatsApp checkout remains configured for 8008564974

## Important
This is ready for local integration/testing. A production payment gateway still requires the merchant account and server-side API credentials. Do not put those credentials in the website frontend.

## Local test
From `backend/`:
1. `npm install`
2. Set `ADMIN_TOKEN` to a long random value.
3. `npm start`
4. Open `http://localhost:3000/admin/`
